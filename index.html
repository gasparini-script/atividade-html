O que é Engenharia de Software?

Eu pensava que Engenharia de Software era só programar. Pelo que estou aprendendo, também é preciso planejar e testar os programas para que eles funcionem bem para as pessoas.

Ainda estou no primeiro ano e muita coisa é nova para mim. Estou começando pelo básico, como montar uma página usando HTML.

O que estou aprendendo

Por enquanto, estou estudando:

  • Como organizar uma página com HTML;
  • Para que servem algumas tags;
  • Como deixar o código mais fácil de entender.

Como costumo estudar

Quando vou praticar, tento seguir estes passos:

  1. Releio o conteúdo da aula;
  2. Faço um exemplo simples;
  3. Anoto o que ainda não entendi.
