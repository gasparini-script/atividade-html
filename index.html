O que é Engenharia de Software?

Antes, eu pensava que Engenharia de Software era quase só aprender a programar. Agora estou vendo que também envolve planejar, testar e organizar o trabalho para que os programas funcionem bem para quem vai usar.

Estou no primeiro Ano, então tenho muita coisa para aprender. Mas fico tranquilo em saber que estou em uma boa instituição que é a UniFil.

Coisas que estou aprendendo

Estou começando pelo básico. Quando pratico os assuntos em exemplos pequenos, consigo entender melhor como cada parte se encaixa:

  • Estrutura básica de uma página com HTML;
  • Como organizar o conteúdo usando tags semânticas;
  • A importância de escrever código fácil de entender.

Como costumo estudar

Quando vou estudar, tento seguir estes passos:

  1. Reviso o assunto visto na aula;
  2. Faço um exemplo pequeno para praticar;
  3. Anoto as dúvidas para pesquisar ou perguntar depois.

Um link útil

Se eu fico com dúvida sobre uma tag, posso consultar a documentação de HTML da MDN. Ela abre em outra aba e traz exemplos.
